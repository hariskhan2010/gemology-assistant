# Advanced Gemological Techniques

A reference guide for analytical instrumentation and methodologies used in gemological laboratories for identification, origin determination, treatment detection, and synthetic distinction.

---

## 1. Fourier-Transform Infrared Spectroscopy (FTIR)

### Principle

FTIR measures molecular vibrations in the infrared range (400–4000 cm⁻¹). When infrared radiation is absorbed by a sample, molecular bonds vibrate at characteristic frequencies. The resulting absorption spectrum provides a "fingerprint" of functional groups present. In gemology, FTIR is typically performed in transmission (for thin or powdered samples) or reflectance mode (for mounted stones). Most gem-quality stones are analyzed using diffuse reflectance infrared Fourier transform (DRIFT) or direct transmission through polished parallel windows.

### Key Absorption Features

| Wavenumber (cm⁻¹) | Assignment | Application |
|--------------------|------------|-------------|
| 3309 | OH stretching in corundum | Natural vs. synthetic ruby/sapphire; geographic origin |
| 3640 | Channel water in beryl | Emerald, aquamarine identification |
| 2800–3200 | C-H stretching (organic polymers) | Polymer/oil in emerald and jadeite |
| 1735 | C=O carbonyl | Resin/plastic fillers |
| 1510, 1600 | Aromatic ring stretches | Epoxy resins in emerald |
| 1282 | Type IaA diamond (aggregated N pairs) | Diamond type classification |
| 1175 | Type IaB diamond (four N atoms) | Diamond type classification |
| 1344 | Single substitutional nitrogen (Ib) | Synthetic diamond (HPHT type Ib) |
| 1430 | Hydrogen-related platelets (IaB) | Natural diamond aging indicator |
| 3107 | Hydrogen in diamond | Brown color related |

### Applications

#### Diamond Typing

FTIR is the standard method for diamond type classification (Ia, Ib, IIa, IIb):

- **Type IaA (1282 cm⁻¹):** Nitrogen pairs — ~98% of natural diamonds
- **Type IaB (1175 cm⁻¹):** Four nitrogen atoms + vacancy — natural aggregates
- **Type Ib (1344 cm⁻¹, 1130 cm⁻¹):** Single substitutional nitrogen — rare in nature, common in HPHT synthetic
- **Type IIa:** No measurable nitrogen absorption — extremely rare natural (e.g., Cullinan, Golconda), common in CVD synthetic
- **Type IIb:** Boron acceptor (2800 cm⁻¹ continuum) — natural blue diamonds

#### Treatment Detection

**Corundum (ruby/sapphire):**
- Natural corundum shows sharp OH stretching bands near 3309 cm⁻¹
- Heat-treated corundum loses/diffuses these OH bands
- Synthetic corundum has no OH bands (flux-grown) or broad water bands (hydrothermal)
- Beryllium-diffused sapphire shows altered IR patterns

**Emerald (beryl):**
- Natural emerald shows Type I and Type II water peaks in channels
- Hydrothermal synthetic emerald has different water ratios
- Oil/resin fillers show C-H stretches at 2800–3200 cm⁻¹ and C=O at 1735 cm⁻¹
- Different fillers have distinct spectra: cedar oil (organic), ExCel, Opticon, Permasafe

**Jadeite:**
- Type A (natural, untreated): No polymer peaks
- Type B (polymer-impregnated): C-H stretches at 2800–3200 cm⁻¹, C=O at 1735 cm⁻¹
- Quantifiable: polymer content can be estimated from peak intensity

#### Natural vs. Synthetic Distinction

- **Flux-grown emerald/alexandrite:** No water peaks at 3640/3690 cm⁻¹ (water absent in flux environment)
- **Hydrothermal synthetic emerald:** Type II water dominates over Type I (ratio differs from natural)
- **Synthetic diamond type Ib:** Strong single nitrogen peaks at 1344 cm⁻¹, absent in most naturals
- **HPHT synthetic diamond:** Ib character + nitrogen aggregation gradient

#### Geographic Origin

In corundum, the OH stretching region (3300–3500 cm⁻¹) varies by locality:
- **Burma (Myanmar) ruby:** Strong 3309 cm⁻¹, sharp 3319 cm⁻¹ shoulder
- **Mogok ruby:** Characteristic OH pattern
- **Sri Lanka sapphire:** Distinct water features
- **Madagascar sapphire:** Weak OH signature

### Instrument Considerations

- **Resolution:** Typically 4–8 cm⁻¹ for gemological work
- **Aperture:** Variable rectangular aperture to isolate clean sample area
- **Detector:** MCT (mercury cadmium telluride) cooled by liquid nitrogen for highest sensitivity; DTGS (deuterated triglycine sulfate) for room-temperature operation
- **Scan time:** 32–256 scans averaged (30 sec–3 min per spectrum)

## 2. Raman Spectroscopy

### Principle

Raman spectroscopy measures inelastic scattering of monochromatic laser light. Most photons scatter elastically (Rayleigh scattering — same wavelength). A tiny fraction (~1 in 10⁷) scatters inelastically, gaining or losing energy from molecular vibrations. The energy shift (Raman shift, in cm⁻¹) corresponds to specific molecular vibrations, producing a unique spectral fingerprint for each mineral.

Advantages: Non-destructive, works through transparent or translucent gems, through plastic/paper packaging, and even through water. Requires no sample preparation. Can be performed on mounted stones. Spatially resolved (Raman mapping) down to ~1 µm.

### Applications

#### Mineral Identification

Every mineral has a unique Raman fingerprint. Raman can identify:

- **Gem species:** The most definitive technique for mineral identification when refractive index/SG are ambiguous
- **Polymorphs:** Distinguishes diamond (1332 cm⁻¹) from moissanite (780, 970 cm⁻¹); distinguishes rutile from anatase
- **Uncut rough:** Identify rough stones through skin/natural coating

Common reference peaks:

| Mineral | Major Raman Peak(s) (cm⁻¹) |
|---------|---------------------------|
| Diamond | 1332 |
| Moissanite | 780, 970 |
| Corundum | 417, 644 |
| Beryl | 684, 1067 |
| Quartz | 464, 205 |
| Zircon | 1008, 974, 439 |
| Spinel | 406, 667 |
| Topaz | 927, 515, 449 |
| Turquoise | 1042, 1231 |
| Jadeite | 1038, 698, 375 |
| Nephrite | 1055, 678, 369 |
| Opal | 465 (broad) |
| Pearl | 1085 (aragonite), 1136 (vaterite) |

#### Inclusion Identification

Raman can identify inclusions non-destructively through the host gem. Critical for:

- **Natural vs. synthetic:** Natural corundum often contains rutile needles, apatite, zircon, calcite; synthetic contains flux or metallic inclusions
- **Geographic origin:** Specific inclusion mineral suites are characteristic of deposits
- **Treatment detection:** Borax residue, glassy flux residues
- **Fluid inclusions:** Raman identifies liquid/gas/vapor composition (CO₂, H₂O, hydrocarbons)

#### Treatment Detection

**Emerald fillers:** Raman distinguishes common fillers:
- **Cedar oil:** C-H stretches at 2800–3100 cm⁻¹ (similar to FTIR)
- **Canada balsam:** Unique fingerprint at 1700 cm⁻¹
- **ExCel (polymer):** Strong peaks at 1450, 1730, 2800–3100 cm⁻¹
- **Permasafe (UV-cured epoxy):** 1610, 1510 cm⁻¹ aromatic ring peaks
- **Opticron:** Complex peak pattern distinct from natural emerald
- **Palm oil:** Specific fatty-acid ester signature

**Polymer in jadeite (B-jade):**
- Epoxy peaks at 1110, 1186, 1608, 3060 cm⁻¹ superimposed on jadeite spectrum

**Heat treatment in corundum:**
- Zircon inclusions convert from high-zircon to low-zircon form (detectable by Raman shift)
- Boehmite (AlOOH) dehydration at ~450°C — presence indicates unheated

**Diamond graphitization:**
- Laser drilling or HPHT creates graphitic inclusions (diamond (1332 cm⁻¹) + graphite (1580 cm⁻¹) + amorphous carbon (1350 cm⁻¹))

#### Strain Mapping

Raman peak shifts reveal residual stress in diamond, corundum, and other gems:

- Diamond 1332 cm⁻¹ peak shifts ±2 cm⁻¹ under stress
- Compressive stress → peak shifts to higher wavenumber
- Tensile stress → peak shifts to lower wavenumber
- Used in HPHT diamond quality assessment

### Instrument Considerations

| Laser | Wavelength | Best For |
|-------|-----------|----------|
| 532 nm (green) | Most common | General purpose; strong signal |
| 633 nm (red) | Reduced fluorescence | Fluorescent gems, diamonds |
| 785 nm (NIR) | Minimal fluorescence | Highly fluorescent samples |
| 830 nm (NIR) | Minimal fluorescence | Organic gems, resin fillers |

- **Fluorescence interference:** Many gems fluoresce, masking weak Raman signals. Use longer wavelength laser (785 nm) or subtract baseline.
- **Resolution:** ~2–4 cm⁻¹ typical for gemological work
- **Spatial resolution:** ~1–2 µm with confocal optics

## 3. X-Ray Fluorescence (XRF / ED-XRF)

### Principle

XRF measures elemental composition by exposing a sample to high-energy X-rays, which eject inner-shell electrons. Outer electrons fill the vacancy, emitting characteristic fluorescent X-rays. The energy and intensity of emitted X-rays identify elements present and their approximate concentrations.

Energy-dispersive XRF (ED-XRF, also EDXRF) uses a solid-state detector to measure all elements simultaneously. Most common in gemological labs for non-destructive elemental analysis.

### Detection Range

- Elements from Na (11) to U (92)
- Limit of detection: ~10–100 ppm for most elements (much lower for higher-Z elements)
- Cannot detect: H, He, Li, Be, B, C, N, O, F, Ne (light elements)

### Applications

#### Lead Detection in Glass-Filled Ruby

Lead-rich glass filler is detected by strong Pb Lα and Lβ peaks. Even trace lead (from flux residues) is easily identified. This is the primary screening method for glass-filled corundum.

**Indicators:**
- Lead content >100 ppm strongly suggests glass filling
- Combined with high Si, Ca, Ba content
- Homogeneous (surface scan) vs. heterogeneous distribution (map scanning)

#### Trace Element Fingerprinting for Geographic Origin

Trace element ratios differentiate geographic sources:

| Pair | Application |
|------|-------------|
| Fe/Mg vs. Fe/Ti | Ruby origin (Burma, Thailand, Mozambique, Madagascar) |
| Fe/Cr vs. Fe/Ti | Sapphire origin (Kashmir, Sri Lanka, Madagascar, Montana) |
| Cr/Ga vs. Fe/V | Emerald origin (Colombia, Zambia, Brazil, Afghanistan) |
| Fe vs. Cr | Spinel origin |
| Cr/Ga | Tsavorite vs. demantoid |

**Key discriminants for corundum:**
- **Burma ruby:** Low Fe, low Ga, high Cr/Ga ratio
- **Mozambique ruby:** Higher Fe, Ti, Ga
- **Kashmir sapphire:** Low Fe, low Ti, characteristic Cr/Ga
- **Sri Lanka sapphire:** High Ga, low Fe, Zr present
- **Montana sapphire:** High Fe, high Ga, low Ti

#### Coated Stone Detection

Surface coatings (e.g., titanium on mystic topaz, metal oxide on coated sapphire) show anomalous surface-dominated element concentrations. Compare surface scan vs. bulk internal scan.

#### Synthetic vs. Natural Distinction

- **Flux-grown synthetic ruby:** High Pb, Mo, Bi (flux residues), low Ga
- **Hydrothermal synthetic emerald:** High Ni, Cu, variable Ni/Cr ratio
- **Czochralski synthetic alexandrite:** High Ir (iridium crucible), very low Fe
- **Natural vs. synthetic spinel:** Different trace element profiles (Fe, Zn, Ga, Ge)

#### Metal Alloy Identification

XRF identifies metal alloy composition in jewelry:
- Karat gold (10K, 14K, 18K, 22K, 24K) — Au, Cu, Ag, Zn ratios
- Platinum — Pt, Ir, Pd, Ru
- Silver — Ag, Cu content
- Nickel presence (relevant for hypoallergenic assessment)

### Limitations

- **No light element detection** (Be, Li, B, C, N, O, F) — cannot detect beryllium diffusion directly
- **Surface sensitive** — effective depth ~10–100 µm, may miss internal features
- **Matrix effects** — absorption/enhancement corrections needed for accurate quantification
- **Detection limits** ~10 ppm for most elements; lower sensitivity for Na, Mg, Al

## 4. LA-ICP-MS (Laser Ablation-Inductively Coupled Plasma-Mass Spectrometry)

### Principle

A focused laser beam (typically 193 nm excimer or 213 nm Nd:YAG) ablates a ~30–80 µm diameter crater on the gem surface. The ablated material is transported by helium carrier gas into an inductively coupled plasma (argon, ~6000 K) where it is atomized and ionized. The ions enter a mass spectrometer (quadrupole, sector-field, or time-of-flight) where they are separated by mass-to-charge ratio and quantified.

The gold standard for gemological trace element analysis. Destructive on a microscopic scale — craters are generally invisible to the naked eye and often invisible under 10× loupe, but technically destructive.

### Capabilities

- **Elements measured:** Li (3) to U (92)
- **Detection limits:** Low ppb (parts per billion) for most elements — 100–1000× more sensitive than XRF
- **Spot size:** 30–80 µm typical (smaller for valuable stones)
- **Depth resolution:** ~0.1–5 µm per laser pulse (depth profiling possible)
- **Quantification:** Requires matrix-matched standards (e.g., NIST SRM 610/612 glass, USGS reference materials)

### Applications

#### Geographic Origin Determination

LA-ICP-MS is the gold standard for geographic origin determination, particularly for corundum. Approximately 50+ trace elements measured simultaneously.

**Ruby origin discriminants:**
| Origin | Fe (ppm) | Cr (ppm) | Ga (ppm) | Ti (ppm) | V (ppm) | Cr/Ga | Fe/Ti |
|--------|----------|----------|----------|----------|---------|-------|-------|
| Burma (Mogok) | 10–500 | 2000–8000 | 20–80 | 10–100 | 10–50 | 30–400 | 1–10 |
| Burma (Mong Hsu) | 50–200 | 1000–3000 | 30–80 | 10–50 | 10–50 | 12–100 | 1–20 |
| Mozambique | 200–3000 | 1000–5000 | 50–150 | 50–300 | 10–100 | 10–100 | 1–10 |
| Thailand | 500–5000 | 500–2000 | 40–120 | 50–500 | 5–50 | 5–40 | 1–50 |
| Tanzania | 100–1000 | 1000–4000 | 40–100 | 50–300 | 10–80 | 15–80 | 1–10 |
| Madagascar | 100–1000 | 2000–6000 | 30–100 | 20–200 | 10–80 | 20–200 | 1–20 |

**Sapphire origin discriminants:**
- **Kashmir:** Low Fe (<50 ppm), low Ti, low Ga, elevated Cr
- **Sri Lanka:** High Ga (>80 ppm), low Fe (<200 ppm), Zr present
- **Madagascar:** Intermediate Fe, Ga 50–100 ppm, low Mg
- **Montana:** High Fe (500–2000 ppm), high Ga
- **Australia:** Very high Fe (1000–10,000 ppm), low Cr, high Mg

**Emerald origin discriminants:**
- **Colombia:** Low Fe (<500 ppm), high Cr/V, low Na, low Cs
- **Zambia:** High Fe (2000–10,000 ppm), high Na, high Cs, low Cr/V
- **Brazil:** Variable Fe, high Cs, high Li
- **Afghanistan:** Moderate Fe, moderate Cr/V
- **Ethiopia:** Fe 500–2000 ppm, Cr 1000–3000 ppm

#### Beryllium Diffusion Detection

Beryllium (Be) is undetectable by standard XRF. LA-ICP-MS detects Be at ppb levels, making it the definitive method for:

- **Depth profile analysis:** Measure Be concentration from surface to interior
- **Natural Be:** Uniform distribution throughout the stone (0.1–50 ppb in corundum)
- **Diffusion-treated Be:** High surface concentration (10–500 ppm) decreasing inward over 100–500 µm
- **Detection threshold:** >50 ppb Be in corundum is suspicious; >1 ppm with surface gradient confirms diffusion treatment

#### Synthetic vs. Natural Distinction

- **Natural corundum:** Characteristic trace element variability, consistent zoning
- **Hydrothermal synthetic ruby:** High Ni, Ni/Cr ratio differs from natural
- **Flux-grown ruby:** Flux-related elements (Pb, Mo, Bi, Pt, Fe) in trace amounts
- **Czochralski synthetic:** High purity, very low Fe, Co (crucible contamination)
- **HPHT synthetic diamond:** Ni, Co, Fe (catalyst metals) present
- **CVD diamond:** Si present (substrate contamination)

### Limitations

- **Destructive** — a microscopic crater remains (30–80 µm diameter, ~5–30 µm deep)
- **Requires flat surface** or slight ablation of curved surface
- **Standard-dependent** — quantification accuracy limited by standard matching
- **Slow** relative to XRF (5–15 min per analysis including standard calibration)
- **Cost** — expensive instrumentation ($200K–$500K) and per-analysis cost

## 5. UV-Vis-NIR Spectroscopy

### Principle

UV-Vis-NIR spectroscopy measures light absorption in the ultraviolet (190–400 nm), visible (400–750 nm), and near-infrared (750–1100 nm) ranges. Electrons in transition metal ions (Cr³⁺, Fe²⁺/³⁺, V³⁺, Mn²⁺, Ti³⁺, etc.) absorb specific wavelengths, producing color. The absorption spectrum reveals which chromophores are present, their oxidation states, and their coordination environment.

### Applications

#### Color Origin Determination

Identifies the specific chromophores responsible for gem color:

| Gemstone | Chromophore(s) | Key Absorption Features |
|----------|---------------|-----------------------|
| Ruby | Cr³⁺ | 410, 550 nm (cause red) + 694 nm (fluorescence) |
| Sapphire (blue) | Fe²⁺–Ti⁴⁺ intervalence charge transfer | Broad band at 580 nm, 450, 380 nm Fe bands |
| Emerald | Cr³⁺ + V³⁺ | 430, 608, 683 nm |
| Alexandrite | Cr³⁺ | 380, 420, 480, 580, 645 nm (color change) |
| Amethyst | Fe⁴⁺ (irradiation-induced) | 540 nm broad band |
| Citrine | Fe³⁺ | 440 nm tail |
| Peridot | Fe²⁺ | 492, 528, 630 nm |
| Tanzanite | V³⁺ | 420, 530, 590 nm (pleochroic) |
| Spinel (blue) | Co²⁺ | 540, 580, 620, 660 nm triple peaks |
| Demantoid | Fe³⁺ + Cr³⁺ | 440 nm Cr band |
| Jadeite (green) | Cr³⁺ | 620, 660, 690 nm |
| Tsavorite | V³⁺ + Cr³⁺ | 420, 600, 660 nm |

#### Treatment Detection

**Heat treatment in corundum:**
- Unheated: Fe³⁺ peaks at 377, 388, 450 nm sharp
- Heated: Fe³⁺ peaks diminish, color-center bands disappear
- Low-temperature heating (pink sapphire): 377 nm Fe³⁺ peak reduces
- High-temperature heating (blue sapphire): Diffuses Ti, alters broad band

**Heat treatment in tanzanite:**
- Unheated green/brown: Broad absorption across visible
- Heated blue/purple: V³⁺ absorption at 420, 530, 590 nm dominant
- Spectrum shifts to characteristic blue-violet profile

**Irradiation detection:**
- Diamond: GR1 (741 nm) — zero-phonon line indicates irradiation damage
- Irradiated topaz: Color center bands at 470, 380 nm
- Irradiated quartz: Smoky quartz centers at 440, 620 nm (disappear with heating)
- Irradiated blue maxixe beryl: Distinct absorption at 685 nm (pink/red maxixe type)

**HPHT diamond:**
- Annealing removes/reduces GR1, creates H3 (503 nm), H4 (496 nm) centers
- Optical centers indicate annealing temperature (1700–2200°C range)

#### Synthetic vs. Natural

- **Synthetic ruby (Verneuil):** Cr³⁺ bands sharper, higher Cr, lower Fe → weak/no Fe absorption at 450 nm
- **Synthetic emerald:** Cr³⁺ peaks different from natural due to different V/Cr ratio environment
- **CVD diamond:** Very low nitrogen, sharp NV centers at 575, 637 nm

### Instrument Considerations

- **Spectral range:** 200–1100 nm typical for gemology (UV-Vis-NIR)
- **Resolution:** 0.5–2 nm
- **Measurement mode:** Transmission (loose stones) or reflectance (mounted stones)
- **Low-temperature (77K):** Sharpens absorption features significantly

## 6. Photoluminescence (PL) Spectroscopy

### Principle

A laser excites electrons in the gem material, which then relax and emit light (luminescence). The emission spectrum reveals defect centers, trace elements, and structural imperfections. PL is exceptionally sensitive — can detect defect centers at concentrations as low as 1 ppb.

In gemology, PL is most important for diamond analysis, though it is also used for corundum, emerald, and other gems.

### Key Defect Centers in Diamond

| Center | Emission (nm) | Origin | Application |
|--------|--------------|--------|-------------|
| NV⁰ | 575 | Nitrogen-vacancy (neutral) | HPHT, CVD, treated diamond |
| NV⁻ | 637 | Nitrogen-vacancy (negative) | HPHT, radiation + anneal |
| H3 | 503 | N-V-N (two N + vacancy) | Natural diamond, HPHT annealing |
| H4 | 496 | N-V-N complex (four N) | Natural Type Ia |
| SiV | 737 | Silicon-vacancy | CVD diamond (Si substrate) |
| GeV | 602 | Germanium-vacancy | CVD diamond |
| Ni-related | 483, 523, 659 | Nickel complexes | HPHT synthetic (Ni catalyst) |
| GR1 | 741 | Vacancy (V⁰) | Irradiation damage |
| N3 | 415 | Three N + vacancy | Natural diamond (Type Ia) |
| S1 | 442–535 | Dislocation-related | Plastic deformation |
| 490.7 | 491 | H2 center (N-V-N⁻) | HPHT, type Ia |
| 3H | 503.4 | Interstitial-related | Irradiation + low-T anneal |

### Applications

#### Diamond Origin Determination (Natural vs. HPHT vs. CVD)

**Natural diamond:**
- Strong N3 center at 415 nm (natural aggregation)
- H3 center at 503 nm common
- Weak/no SiV at 737 nm
- No Ni-related centers
- NV centers usually weak or absent in pristine natural

**HPHT synthetic diamond:**
- Ni-related centers at 483, 523, 659 nm (nickel catalyst)
- Strong NV⁰ (575) and NV⁻ (637) after HPHT annealing
- H2 center at 491 nm common
- Ib nitrogen (1344 cm⁻¹ in FTIR) + Ni in PL
- No N3 center

**CVD synthetic diamond:**
- SiV at 737 nm (silicon from substrate) — very strong, sharp
- GeV at 602 nm if germanium present
- NV⁰ (575) and NV⁻ (637) common
- Weak or absent N3
- Hydrogen-related centers near 500–600 nm

#### HPHT Annealing Detection

HPHT annealing (brown to colorless/pink) creates characteristic centers:
- H3 (503 nm) — increases with HPHT
- H4 (496 nm) — increases with HPHT
- NV centers — form at high temperatures
- 490.7 nm (H2) — HPHT indicator

#### Irradiation Detection

- GR1 (741 nm) — definitive sign of irradiation damage
- Followed by annealing: NV centers form from mobilized vacancies
- 3H center (503.4 nm) — irradiation + low-temperature annealing
- H2 (491 nm) — irradiation + annealing of Type Ia

#### Low-Temperature PL

At liquid nitrogen temperature (77 K), linewidths narrow and sensitivity increases:
- NV center: 2–3× sharper at 77K vs. room temperature
- SiV: Resolution of fine structure
- Trace nickel peaks: Detectable only at low temperature

#### Corundum PL

PL is also used for corundum:
- **Cr³⁺ emission:** R1 (694 nm), R2 (693 nm) lines — natural vs. synthetic differences in width
- **Natural:** Sharper, lower strain → narrower R lines
- **Flux synthetic:** Very narrow R lines, different sideband structure
- **Heat treatment detection:** Changes in Cr³⁺ sideband and Ti³⁺ emission

### Instrument Considerations

- **Excitation lasers:** 488 nm (argon ion), 514 nm, 532 nm, 633 nm, 785 nm
- **Cooling:** 77K cryostat greatly improves sensitivity for diamonds
- **Spectral range:** 200–1100 nm (UV-Vis-NIR)
- **Collection:** Confocal optics for spatial resolution ~1–5 µm

## 7. DiamondView™ Imaging

### Principle

The DiamondView™ (De Beers / DTC instrument) uses deep ultraviolet (UV) excitation at ~225 nm from a xenon lamp. At this wavelength, diamond has a bandgap of 5.47 eV (~225 nm), inducing fluorescence and phosphorescence characteristic of growth structure.

The diamond is mounted facing the detector, and deep UV floods the crown. A sensitive CCD camera captures the emitted fluorescence image. The image reveals internal growth structures, zoning, and sector patterns invisible under normal illumination.

### Applications

#### Natural vs. Synthetic Diamond

The gold standard for distinguishing natural from synthetic diamond:

| Feature | Natural Diamond | HPHT Synthetic | CVD Synthetic |
|---------|----------------|----------------|---------------|
| Growth pattern | Octahedral (square/rectangular zoning), irregular, complex | Cubo-octahedral (square cross, sectors), metallic inclusions | Striated, layered, parallel growth bands |
| Zoning | Angular, sharp | Geometric, sector-specific | Planar, parallel |
| Fluorescence | Blue, green, yellow (variable) | Often strong blue (cubo-octahedral sectors) | Orange-red to green (wavelength shifts) |
| Phosphorescence | Rare, weak if any | Strong blue/green (boron — Type IIb) | Variable, often weak |
| Inclusions | Dark, irregular | Metallic (Ni-Fe-Co) flux inclusions | Graphitic, dark specks |

**HPHT synthetic:**
- Square or rectangular growth sectors (cubo-octahedral)
- Yellow/green fluorescence in cube sectors; blue in octahedral sectors
- Dark metallic inclusions common
- Strong phosphorescence in blue/boron-bearing sectors

**CVD synthetic:**
- Layered, parallel striations (planar growth)
- Often orange-red fluorescence with green bands
- Columnar structure visible on edge
- Silicon-related defects

**Natural:**
- Irregular, complex growth patterns
- Octahedral zoning (square/rectangular, sometimes dissolved or rounded)
- Blue/green fluorescence variable
- Rarely shows metallic inclusions

#### HPHT Annealing Patterns

HPHT treatment of natural brown diamonds creates:
- Diffusion halos around inclusions
- Decoration of internal graining
- "Cross-hatched" strain patterns
- Color concentration in specific growth sectors

#### Growth Zoning Analysis

- **Color zoning:** Correlates fluorescence with color distribution
- **Nitrogen distribution:** Non-uniform incorporation visualized
- **Plastic deformation:** Dislocation networks appear as luminescent patterns

### Limitations

- Instrument cost: ~$60,000–$100,000 (proprietary instrument)
- Requires clean, reasonably transparent diamond
- Some natural diamonds show unusual patterns (e.g., coated stones)
- CVD diamonds with special treatments can mimic natural patterns

## 8. LIBS (Laser-Induced Breakdown Spectroscopy)

### Principle

A high-energy pulsed laser (typically Nd:YAG at 1064 nm) ablates a microscopic amount of the gem surface, creating a plasma plume. The plasma emission is collected and analyzed by a spectrometer. Each element emits characteristic wavelengths, and intensity correlates with concentration.

Spatial resolution: 50–200 µm. Detection limits: 1–100 ppm for most elements. Particularly sensitive to light elements (Li, Be, B) that are difficult by XRF.

### Applications

#### Beryllium Detection

- **Primary use:** Beryllium diffusion treatment detection in corundum
- **Sensitivity:** ~2 ppm for Be (adequate for detecting diffusion treatment)
- **Depth profiling:** Multiple laser pulses at same spot measure Be concentration vs. depth
- **Natural Be:** 0.1–50 ppb in corundum (below LIBS detection limit)
- **Diffused Be:** >1 ppm surface concentration with decreasing gradient
- **Detection threshold:** >50 ppb is suspicious; >1 ppm confirms treatment

#### Light Element Analysis

LIBS detects elements inaccessible to ED-XRF:

| Element | Wavelength (nm) | Application |
|---------|----------------|-------------|
| Li | 670.8 | Origin discrimination, pegmatite gems |
| Be | 313.0, 234.9 | Beryllium diffusion in corundum |
| B | 249.7, 249.8 | Natural vs. synthetic; origin (tourmaline) |
| C | 247.9 | Diamond vs. simulant |
| N | 746.8, 742.3 | Diamond type |
| O | 777.2 | Stoichiometry, origin |
| F | 685.6 | Topaz, fluorite identification |
| Na | 589.6, 589.0 | Feldspar, jadeite |

#### Geographic Origin Fingerprinting

Elemental ratios from LIBS can be used for origin discrimination, though less comprehensive than LA-ICP-MS due to fewer elements and higher detection limits.

#### Treatment Detection

- **Diffusion treatment (Be, Ti, Cr):** Surface-concentrated element profiles
- **Glass-filled ruby:** Pb, Si, Ba, Ca (glass elements)
- **Coated stones:** Anomalous surface element concentration

### Comparison with LA-ICP-MS

| Aspect | LIBS | LA-ICP-MS |
|--------|------|-----------|
| Crater size | 50–200 µm | 30–80 µm |
| Depth per pulse | 0.1–1 µm | 0.1–5 µm |
| Detection limits | 1–100 ppm | 0.001–1 ppm (ppb level) |
| Light elements | Good (Li, Be, B) | Excellent (all) |
| Quantification | Semi-quantitative (±30%) | Quantitative (±5–10%) |
| Standards needed | Fewer (no matrix matching) | Matrix-matched standards |
| Cost | $50K–$150K | $200K–$500K |

## 9. SIMS (Secondary Ion Mass Spectrometry)

### Principle

A focused primary ion beam (Cs⁺, O₂⁺, Ga⁺, or Ar⁺) bombards the sample surface, sputtering secondary ions. These ions are extracted into a mass spectrometer (magnetic sector or quadrupole) for mass-to-charge analysis.

SIMS offers the highest spatial resolution (<1 µm) and exceptional sensitivity (ppb to ppt for most elements). It can measure isotopes and light elements. Destructive (crater typically 1–50 µm).

### Applications

#### Oxygen Isotope Analysis (δ¹⁸O)

The most important gemological application of SIMS. The oxygen isotope ratio (¹⁸O/¹⁶O, expressed as δ¹⁸O relative to SMOW — Standard Mean Ocean Water) varies by geological environment:

**Corundum origin:**
- **Burma ruby:** δ¹⁸O +7 to +12‰ (metamorphic)
- **Mozambique ruby:** δ¹⁸O +3 to +8‰
- **Thailand ruby:** δ¹⁸O +5 to +9‰
- **Sri Lanka sapphire:** δ¹⁸O +5 to +9‰
- **Kashmir sapphire:** δ¹⁸O +9 to +14‰ (very distinct)
- **Madagascar sapphire:** δ¹⁸O +4 to +8‰
- **Montana sapphire:** δ¹⁸O +6 to +12‰

**Synthetic vs. natural corundum:**
- **Verneuil synthetic:** δ¹⁸O ~+5 to +10‰ (overlap with natural)
- **Flux-grown synthetic:** δ¹⁸O +8 to +14‰ (different isotope source)
- **Hydrothermal synthetic:** δ¹⁸O matches water source (often very different from natural, can be negative)
- **Czochralski:** δ¹⁸O varies by feedstock

Oxygen isotope analysis is the most definitive method for distinguishing natural from synthetic corundum when other methods are ambiguous.

#### Trace Element Analysis

- **High spatial resolution:** <1 µm analysis of inclusions and growth zones
- **Ultra-sensitive:** ppb detection levels for most elements
- **Depth profiling:** <10 nm depth resolution (element distribution in thin surface coatings)
- **Full periodic table** including light elements

#### Diamond Analysis

- Nitrogen content and aggregation state
- Boron in Type IIb diamonds
- Hydrogen and hydrogen-related defects
- Trace element (Ni, Co, Si) distribution in synthetic diamonds

### Limitations

- **Destructive** — ~1–50 µm crater for most analyses
- **Quantification difficult** — matrix effects, requires extensive standards
- **Expensive** — $500K–$1.5M instrument cost; $500–$2000 per analysis
- **Slow** — sample preparation, vacuum, data acquisition
- **Sample preparation** — must be clean, flat, coated with conductive layer

## Notes on Methodology

### Sample Preparation Requirements

| Technique | Mounted Stone? | Polished Surface? | Minimum Size |
|-----------|---------------|-------------------|-------------|
| FTIR | ✓ (reflectance) | ✓ (transmission) | ~1 mm |
| Raman | ✓ | ✓ | ~50 µm |
| XRF | ✓ | No | ~1 mm |
| LA-ICP-MS | ⚠ (best flat) | ✓ | ~2 mm |
| UV-Vis-NIR | ✓ (reflectance) | ✓ (transmission) | ~1 mm |
| PL | ✓ | ✓ | ~100 µm |
| DiamondView | ✓ | ✓ (crown) | ~1 mm |
| LIBS | ✓ | No | ~2 mm |
| SIMS | ⚠ (chuck mount) | ✓ (polished) | ~3 mm |

### Destructive vs. Non-Destructive

- **Truly non-destructive:** FTIR, Raman, XRF, UV-Vis-NIR, PL, DiamondView
- **Micro-destructive (crater invisible to naked eye, visible under loupe/microscope):** LA-ICP-MS, LIBS
- **Destructive (visible crater):** SIMS

In practice, the analysis sequence always proceeds from non-destructive to destructive techniques. A typical origin report flow: microscope → UV-Vis-NIR → FTIR → Raman → XRF → LA-ICP-MS (only if needed and with consent).

### Detection Limit Comparison

| Technique | Best Detection Limit |
|-----------|---------------------|
| FTIR | ~10 ppm (functional groups) |
| Raman | ~100–1000 ppm (mineral phases) |
| XRF | ~10–100 ppm (elements Z > 20) |
| LA-ICP-MS | ~0.001–0.1 ppb (most elements) |
| UV-Vis-NIR | ~1–10 ppm (chromophores) |
| PL | ~0.001–0.1 ppb (defect centers) |
| DiamondView | Qualitative (pattern imaging) |
| LIBS | ~1–10 ppm |
| SIMS | ~0.001–1 ppb (varies by element) |
